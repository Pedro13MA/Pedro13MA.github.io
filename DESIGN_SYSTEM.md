# Limiar — Design System (web)

## Direção

Light-first Clean Tech. Fundo `slate-50`, cards brancos, tipografia `slate-900` / `slate-500`, accent sky `#0284c7`.

## Tokens

| Token | Valor | Uso |
|-------|-------|-----|
| `--bg-primary` | `#F8FAFC` | Fundo da página |
| cards | `#FFFFFF` + `border-slate-200/80` + `shadow-sm` | Superfícies |
| `--accent-primary` | `#0284C7` | Gráfico, links |
| buy | `emerald-50/700/200` | Comprar agora |
| fair | `amber-50/700/200` | Preço razoável |
| wait | `rose-50/700/200` | Espera |
| CTA | `bg-slate-900` | Botões de compra |

## Tipografia

- **Display:** Space Grotesk
- **Body:** Source Sans 3
- **Mono:** JetBrains Mono
